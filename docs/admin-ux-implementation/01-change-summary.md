# ADMIN-UX-01 변경 요약

## 기준

- 기준 SHA: `de6a4066a88e3bd2469183e51bb0845569a15e98`
- 작업 브랜치: `feat/admin-ux-navigation-v1`
- 범위: 관리자 UI, 내비게이션, 업무 진입 동선
- 제외: API, 데이터 저장 구조, 권한 판정, Firestore Rules, GAS/Drive/Sheets, 운영 데이터

## 변경 전

- 관리자 사이드바에 기능 8개가 같은 깊이로 나열됐다.
- `제출·보고 관리`, `제출 현황`, `교직원 제출·이수 현황`의 관리 단위 차이가 메뉴명만으로 드러나지 않았다.
- 건강검진 유형, 연구부 연수 원본 점검, 법정의무연수 예외 등은 한 화면 안에 있지만 사이드바에서 직접 찾을 수 없었다.
- 교육 상세 화면은 교육 전용 내비게이션만 제공해 전체 관리자 맥락으로 돌아가는 경로가 약했다.

## 변경 후

- `관리자 홈`을 첫 항목으로 고정했다.
- 기존 기능을 `제출·검토`, `검진·검사`, `교육·연수`, `계정·권한`, `감염병`으로 그룹화했다.
- 현재 업무 그룹을 자동으로 펼치고 현재 하위 메뉴를 강조한다.
- 관리자 화면에 `관리자 홈 > 업무 그룹 > 현재 업무` breadcrumb를 제공한다.
- 제출 관련 세 메뉴에는 문서, 대상자, 최종 완료라는 관리 단위 설명을 표시한다.
- 기존 화면의 실제 섹션으로 이동하는 query/hash 바로가기를 추가했다.
- 비동기 렌더 후 대상 섹션이 나타났을 때 스크롤과 포커스를 적용한다.
- 별도검사 운영 도우미는 `연동 예정`인 비활성 행으로만 표시하며 작동하는 링크로 보이지 않게 했다.
- 대시보드 빠른 이동을 업무 우선순위 6개로 정리했다.
- 교육 상세는 최상위 관리자에게만 관리자 breadcrumb와 복귀 링크를 제공한다. `training_admin`은 기존 교육센터 범위만 유지한다.

## 불변 계약

- 등록된 45개 route와 기존 redirect를 유지했다.
- 기존 URL을 삭제하거나 교체하지 않았다.
- 각 페이지의 기존 인증 gate와 서버 권한 검사를 유지했다.
- 데이터 조회, 집계, 제출, 완료 판정, 교육·QR·출석 로직을 변경하지 않았다.
- API 함수는 12개로 유지했다.

## 개인정보 및 운영 영향

- 화면 검수는 운영 데이터와 연결되지 않은 합성 관리자 화면으로 수행했다.
- 실제 성명, 이메일, staffId, 제출자료, 출석자료를 사용하지 않았다.
- Production read/write, Firebase·Drive·Sheets·GAS 변경은 0건이다.
