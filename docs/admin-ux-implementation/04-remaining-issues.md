# 남은 확인 사항

## 배포 전 실제 인증 QA

합성 브라우저 검수로 레이아웃과 상호작용은 확인했지만, 이번 작업에서는 운영 또는 QA Firebase 계정으로 로그인하지 않았다.

QA Preview에서 다음을 최종 확인해야 한다.

1. `health_teacher/admin`으로 관리자 8개 기존 화면 직접 접근
2. `training_admin`으로 교육 운영·대상·QR·출석·등록부 접근
3. `training_admin`에게 관리자 홈과 타 업무 그룹이 노출되지 않는지 확인
4. staff/homeroom의 관리자 route 차단 유지
5. 각 hash 바로가기에서 실제 비동기 데이터 로드 후 목표 섹션 포커스
6. 브라우저 새로고침과 뒤로가기 후 활성 그룹·항목 복원

실제 개인정보가 표시되는 운영 화면 캡처는 만들지 않는다.

## 별도검사 운영 도우미

- `/firebase-checkups/live`는 이번 범위에서 구현하지 않았다.
- 현재 메뉴는 `연동 예정` 비활성 상태만 표시한다.
- 후속 연동 시 별도 권한·API·학교별 데이터 범위를 먼저 확정해야 한다.

## 기존 테스트 환경

- Windows QA GAS 생성물 비교와 Rules 안전성 테스트 2건은 변경 전에도 동일하게 실패한다.
- 이번 기능과 분리된 하네스 개선 작업으로 처리해야 한다.

## 배포 범위

- 이번 브랜치는 UI·내비게이션 변경만 포함한다.
- main 병합, 원격 push, PR, Production 배포는 수행하지 않는다.
- 운영 데이터 read/write는 수행하지 않았다.
