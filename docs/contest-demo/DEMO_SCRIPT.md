# 온라인 보건실 공모전 시연 대본

총 4분. 시작 직전 `시연 제어 → 전체 데모 데이터 초기화 → 닫기`로 일반 교직원 홈을 엽니다. 진행 중에는 브라우저 탭을 유지합니다.

| 시간 | 화면과 클릭 순서 | 발표 문장 | 핵심 메시지와 대체 진행 |
| --- | --- | --- | --- |
| 0:00–0:25 | 온라인 보건실 홈 상단의 가상 데이터 안내와 역할 표시 | “온라인 보건실의 제출, 교육, 검사 안내 흐름을 가상 교직원 12명과 가상 학급 6개로 시연합니다. 이 화면은 별도로 실행되며 모든 조작은 이 탭에만 반영됩니다.” | 역할과 데이터 범위를 소개합니다. 첫 화면이 다르면 시연 제어에서 A를 선택합니다. |
| 0:25–1:10 | A · 홈에서 `검진 안내 보기 → 제출할 자료 확인 → 가상 확인자료 제출` | “일반 교직원은 검진 안내를 읽고 제출할 자료와 상태를 확인합니다. 가상 확인자료를 제출하면 파일명과 제출 시간이 표시됩니다.” | 안내에서 제출까지 이어집니다. 이미 제출되었다면 시연 제어의 `가상 제출 취소`로 교직원 01 상태를 되돌린 후 다시 실행합니다. |
| 1:10–1:55 | B · `시연 제어 → 보건교사` 또는 시나리오 B. 관리자 홈의 `제출·검토 → 대상자별 제출 현황` | “보건교사는 대상자 목록에서 방금 제출한 가상 교직원 01과 아직 미제출인 대상자를 구분합니다. 접수자료 검토와 업무별 완료 현황도 메뉴가 나뉩니다.” | 개인 제출과 관리자 조회가 연결됩니다. 제출 상태가 초기화됐다면 제어 패널로 교직원 01을 가상 제출 완료로 바꿉니다. |
| 1:55–2:55 | C · `교육·연수 → CPR 통합 완료 현황 → 연구부 연수 원본 점검 → 법정의무연수 보고서 열기` | “학교 단체교육과 개별 이수증 경로를 함께 확인합니다. 이어 가상 연구부 원본에서 누락 사례를 찾아 법정의무연수 보고서로 이동합니다. 연구부 담당자는 자신의 교육 관리 메뉴를 사용합니다.” | 교육별 업무와 관리자 범위가 구분됩니다. 메뉴를 찾기 어렵다면 시연 제어의 C를 눌러 CPR 화면을 바로 엽니다. |
| 2:55–3:45 | D · `시연 제어 → D · 별도검사 진행`. 현재·다음 학급과 시간표를 짚고 `시연 제어 → 다음 학급 진행 → 닫기` | “2학년 2반이 진행 중이고 3반이 다음입니다. 다음 학급으로 진행하니 2반은 완료, 3반은 진행 중, 4반은 다음이 되고 마지막 갱신 시각도 바뀝니다. 이 시연에서는 같은 탭 안의 가상 상태가 갱신됩니다.” | 교직원이 학급별 진행 순서를 바로 확인합니다. 상태가 다르면 `가상 검사 초기화` 후 다시 진행합니다. |
| 3:45–4:00 | 검사 현황 화면 유지 | “AI는 공모전 시연본의 기획 구체화, 구현, 테스트 작성에 활용했습니다. 방금 확인한 제출과 이수 상태, 검사 진행은 앱에 정의된 규칙으로 처리합니다.” | 개발 과정과 실행 시 기능을 구분합니다. 브라우저 조작이 어려우면 검수 캡처와 함께 같은 설명으로 마무리합니다. |
