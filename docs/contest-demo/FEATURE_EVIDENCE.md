## 업무 변화와 개인정보

| 업무 | 자료를 개별 확인하는 방식 | 포털에서 시연하는 흐름 |
| --- | --- | --- |
| 검진 확인자료 | 안내와 전달 경로를 각각 찾아 접수 여부 확인 | 안내에서 제출로 이동하고 접수 상태와 대상자별 목록을 확인 |
| 연수 | 교육 이력과 원본 목록을 건별로 대조 | CPR 경로별 완료 현황과 법정의무연수 누락 사례를 업무별 화면에서 확인 |
| 별도검사 | 시간표와 현장 진행을 각각 문의 | 예정 시간표에서 현재 학급과 다음 학급을 함께 조회 |

위 방식 비교는 시연의 업무 흐름을 설명합니다. 기존 현장에서 각 방식이 얼마나 자주 사용되는지 별도로 측정하지 않았습니다. 예상 효과는 반복 확인과 자료 탐색 부담을 줄이는 것입니다. 처리 시간, 문의 건수, 시간 절감률 등의 실제 성과 측정값은 없습니다.

교직원 표시명, 학급 일정, 제출 기록과 연수 상태는 합성했습니다. 학생 단위 식별자와 건강정보는 데모 데이터에 포함하지 않습니다. 가상 역할 전환은 발표 기능이며 실제 사용자 인증이 아닙니다. 상태는 탭 메모리에 저장합니다. 독립 빌드는 운영 SDK와 API를 불러오지 않으며 브라우저 연결을 CSP로 제한합니다.

## AI 활용

Codex를 사용해 기존 앱의 메뉴와 역할 코드를 파악하고, 공모전 시나리오를 화면과 상태 모델로 구현했으며, 가상 데이터와 테스트, 발표 자료 초안을 작성했습니다. 앱 실행 중에는 AI 모델을 호출하지 않습니다. 앱은 정해진 규칙으로 상태를 표시하고 발표자의 조작을 반영합니다.
